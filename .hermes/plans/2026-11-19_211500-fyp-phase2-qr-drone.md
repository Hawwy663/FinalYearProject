# FYP Phase 2 — QR 驅動無人機巡樓 + 網站對接 Implementation Plan

> **For Hermes:** 執行時用 subagent-driven-development，逐個 task 交一個乾淨 subagent，做完 spec review 再做 code review。

**Goal:** 完成老師下週要的里程碑 ——「樓梯間貼幾張系統產生的 QR Code，Tello Talent 起飛、掃到 QR、依 QR 指示飛去下一個目標」，同時把網站由「示範工單」升級成符合 `工作流程.pdf` 20 步流程的正式平台（保安 / 物業管理兩種角色、免輸入、一鍵出 QR 與通告）。

**Architecture:**
- **網站**：React 18 + Vite + Firebase（Firestore / Storage / Auth / Hosting），已有基礎，本階段只加「QR 產生列印」「今日任務」「執行紀錄」「覆核」「報告」。
- **QR 內容**：短、可版本化、帶 checksum 的自訂字串（唔用純 URL，避免長度影響解碼率），payload 直接編碼「我在邊個點、下一步去邊個點、做咩動作」。
- **地面站（ground station）**：一部 laptop 連 Tello WiFi，跑 Python（djitellopy + OpenCV）負責收 UDP 影片、解 QR、發飛行動作、寫 Firestore。Tello 本身唔需要跑自訂 code，所以「有冇機上運算」唔再係阻塞點。
- **AI**：第二階段才接（輕量 object detection，ONNX / YOLO-nano 級），先留好 `aiEngine` / `bboxes` 欄位與上傳介面。

**Tech Stack:** React 18、Vite 5、Firebase 11（Firestore/Storage/Auth/Hosting）、`qrcode` npm、Python 3.11+、`djitellopy`、`opencv-python`（QRCodeDetector）、`firebase-admin`。

## 1. 架構決定（寫落報告用）

### 1.1 QR payload 規格（`FYP1`）

```
FYP1|<zoneId>|<seq>|<action>|<nextZone>|<crc>
```

例：`FYP1|B1F03L2|03|HOLD|B1F04L1|32`（`32` = CRC8，已用實作算法核對過）

| 欄位 | 意思 | 例 |
|---|---|---|
| `FYP1` | 版本前綴，解錯版本即拒收 | `FYP1` |
| `zoneId` | 巡查點（樓層+位置），對應 Firestore `zones/{zoneId}` | `B1F03L2` = B座 3樓 平台2 |
| `seq` | 同一路線的次序（兩位數），用嚟判斷跳步／重複掃 | `03` |
| `action` | 掃到之後做咩：`HOLD`（停低影相）、`TURN90`、`LAND` | `HOLD` |
| `nextZone` | 下一個目標（空 = 完結） | `B1F04L1` |
| `crc` | 前 5 段 CRC8（poly 0x07），防讀錯字元 | `32` |

**為何唔用 URL**：`https://fyp-backstair.web.app/z/B1F03L2` 長 40+ 字元，樓梯光線差、機身晃，QRCodeDetector 解碼率明顯跌；40 字元以內較穩。

### 1.2 地面站職責

1. 連 Tello（`command` → `streamon`）
2. 讀 UDP 11111 H.264 串流 → OpenCV
3. 每 N 幀 `QRCodeDetector.detectAndDecode`
4. 解 payload → 校驗 CRC → 查 `zones/{zoneId}` 動作表
5. 執行動作：影相（`HOLD`）→ 上傳 Storage → 寫 `inspections`；或 `go_xyz_speed` 去下一個點
6. 每一步寫 `runs/{runId}/steps` 記錄（web 即時見到）

> Tello 通訊協定：控制 UDP 8889、狀態 UDP 8890、影片 UDP 11111；狀態含 `tof`、`h`、`bat`、`baro`（[Tello SDK 2.0 文件](https://tmrc.tiec.tp.edu.tw/resfle/upload/RSR20210506102955931/FLE20210506103049OSV.pdf)、[HSRW EOLab wiki](https://wiki.eolab.de/doku.php?id=projects:robomastertt:start)）。

### 1.3 為何不靠 QR 做全屋定位（風險先講）

QR 只解決「依序前進 + 對位」，唔解決「我而家喺邊」。Tello 冇 GPS、室內光流會漂，所以：
- QR 貼在**每一段樓梯的平台**，每次掃到就當「重新定位」（reset drift）
- 飛行距離用短跳（≤1.5m），每跳都掃一次 QR
- `HOLD` 動作時順便用 `h` / `tof` 記錄高度，之後做報告的「拍攝高度」欄

// src/lib/qrPayload.js
const VERSION = 'FYP1';
const ACTIONS = ['HOLD', 'TURN90', 'LAND', 'NONE'];

/** CRC-8/ATM（poly 0x07），回傳兩位大寫 hex */
export function crc8(text) {
  let crc = 0;
  for (const ch of text) {
    crc ^= ch.charCodeAt(0) & 0xff;
    for (let i = 0; i < 8; i += 1) {
      crc = crc & 0x80 ? ((crc << 1) ^ 0x07) & 0xff : (crc << 1) & 0xff;
    }
  }
  return crc.toString(16).toUpperCase().padStart(2, '0');
}

export function encodePayload({ zoneId, seq, action, nextZone = '' }) {
  if (!/^[A-Z0-9]{4,12}$/.test(zoneId)) throw new Error('zoneId 格式錯');
  if (!ACTIONS.includes(action)) throw new Error('action 不正確');
  if (nextZone && !/^[A-Z0-9]{4,12}$/.test(nextZone)) throw new Error('nextZone 格式錯');
  const body = [VERSION, zoneId, String(seq).padStart(2, '0'), action, nextZone].join('|');
  return `${body}|${crc8(body)}`;
}

export function decodePayload(raw) {
  const text = String(raw).trim();
  const parts = text.split('|');
  if (parts.length !== 6) throw new Error('payload 欄位數不正確');
  const [version, zoneId, seq, action, nextZone, sum] = parts;
  if (version !== VERSION) throw new Error(`version 不支援: ${version}`);
  const body = parts.slice(0, 5).join('|');
  if (crc8(body) !== sum.toUpperCase()) throw new Error('checksum 不正確');
  if (!ACTIONS.includes(action)) throw new Error('action 不正確');
  return { zoneId, seq: Number(seq), action, nextZone };
}

export { ACTIONS, VERSION };
```

import { collection, doc, getDoc, getDocs, onSnapshot, orderBy, query } from 'firebase/firestore';
import { db } from '../firebase';

export function listenZones(cb) {
  return onSnapshot(query(collection(db, 'zones'), orderBy('seq', 'asc')), (snap) =>
    cb(snap.docs.map((d) => ({ id: d.id, ...d.data() }))),
  );
}

export async function getZone(zoneId) {
  const snap = await getDoc(doc(db, 'zones', zoneId));
  return snap.exists() ? { id: snap.id, ...snap.data() } : null;
}

export async function listZones() {
  const snap = await getDocs(query(collection(db, 'zones'), orderBy('seq', 'asc')));
  return snap.docs.map((d) => ({ id: d.id, ...d.data() }));
}

import AppBar from '../components/AppBar';

import os
import time
from datetime import datetime, timezone

import cv2
from djitellopy import Tello
import firebase_admin
from firebase_admin import credentials, firestore, storage

from qr_payload import decode_payload  # 下一步 Task A6 建立

BUCKET = "fyp-backstair.firebasestorage.app"
PROJECT = "fyp-backstair"


def init_firebase():
    cred = credentials.ApplicationDefault()
    firebase_admin.initialize_app(cred, {"storageBucket": BUCKET, "projectId": PROJECT})
    return firestore.client(), storage.bucket()


def main():
    db, bucket = init_firebase()
    run = db.collection("runs").document()
    run.set({
        "startedAt": firestore.SERVER_TIMESTAMP,
        "mode": "qr-hop",
        "operator": "field-test",
        "status": "running",
    })
    print(f"run id: {run.id}")

    tello = Tello()
    tello.connect()
    print("battery:", tello.get_battery())
    tello.streamon()
    frame_read = tello.get_frame_read()
    detector = cv2.QRCodeDetector()

    seen = set()
    deadline = time.time() + 120  # 兩分鐘 demo 窗口
    try:
        while time.time() < deadline:
            frame = frame_read.frame
            if frame is None:
                continue
            data, points, _ = detector.detectAndDecode(frame)
            if not data:
                continue
            try:
                payload = decode_payload(data)
            except ValueError as err:
                print("decode error:", data, err)
                continue
            if payload["zoneId"] in seen:
                continue
            seen.add(payload["zoneId"])
            print("QR:", payload)

            shot = f"runs/{run.id}/{payload['zoneId']}-{int(time.time())}.jpg"
            ok, buf = cv2.imencode(".jpg", frame)
            if ok:
                blob = bucket.blob(shot)
                blob.upload_from_string(buf.tobytes(), content_type="image/jpeg")
                print("uploaded:", shot)

            run.collection("steps").add({
                "zoneId": payload["zoneId"],
                "seq": payload["seq"],
                "action": payload["action"],
                "nextZone": payload["nextZone"],
                "photoPath": shot,
                "heightCm": tello.get_height(),
                "tofCm": tello.get_distance_tof() / 10.0,
                "at": firestore.SERVER_TIMESTAMP,
            })
            # TODO(Task A7): 依 payload["action"] 發動作
    finally:
        tello.streamoff()
        tello.end()
        run.update({"status": "finished", "finishedAt": firestore.SERVER_TIMESTAMP})
        print("done, steps:", sorted(seen))


if __name__ == "__main__":
    main()
```

**Step 3: `tools/drone/qr_payload.py`**（同 JS 版一致的 CRC8，避免前後端算法不同）

```python
ACTIONS = {"HOLD", "TURN90", "LAND", "NONE"}
VERSION = "FYP1"


def crc8(text: str) -> str:
    crc = 0
    for ch in text:
        crc ^= ord(ch) & 0xFF
        for _ in range(8):
            crc = ((crc << 1) ^ 0x07) & 0xFF if crc & 0x80 else (crc << 1) & 0xFF
    return f"{crc:02X}"


def decode_payload(raw: str) -> dict:
    parts = raw.strip().split("|")
    if len(parts) != 6:
        raise ValueError("payload 欄位數不正確")
    version, zone_id, seq, action, next_zone, checksum = parts
    if version != VERSION:
        raise ValueError(f"version 不支援: {version}")
    body = "|".join(parts[:5])
    if crc8(body) != checksum.upper():
        raise ValueError("checksum 不正確")
    if action not in ACTIONS:
        raise ValueError("action 不正確")
    return {"zoneId": zone_id, "seq": int(seq), "action": action, "nextZone": next_zone}
```

### Task A8: 離線緩存（解決「連 Tello 就冇網」）

**Files:**
- Create: `tools/drone/outbox.py`
- Modify: `tools/drone/qr_hop.py`

**Step 1: 寫 `outbox.py`** —— 寫唔到 Firestore 就落 local SQLite/JSONL，落地後 `sync`

```python
import json
import os
from datetime import datetime

PATH = os.path.join(os.path.dirname(__file__), "outbox.jsonl")


def enqueue(record: dict) -> None:
    record = {**record, "queuedAt": datetime.utcnow().isoformat()}
    with open(PATH, "a", encoding="utf-8") as fh:
        fh.write(json.dumps(record, ensure_ascii=False) + "\n")


def pending() -> int:
    if not os.path.exists(PATH):
        return 0
    with open(PATH, encoding="utf-8") as fh:
        return sum(1 for _ in fh)


def sync(db) -> int:
    if not os.path.exists(PATH):
        return 0
    sent = 0
    keep = []
    with open(PATH, encoding="utf-8") as fh:
        for line in fh:
            rec = json.loads(line)
            try:
                db.collection("runs").document(rec["runId"]).collection("steps").add(rec["data"])
                sent += 1
            except Exception:
                keep.append(line)
    with open(PATH, "w", encoding="utf-8") as fh:
        fh.writelines(keep)
    return sent
```
