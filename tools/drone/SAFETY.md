# 飛行安全守則（讀完才加 `--fly`）

## 硬件

- [ ] 槳葉保護罩已裝好（Tello Talent 原裝有）
- [ ] 電量 ≥ 60%（程式預設 < 50% 拒絕起飛，但 50% 唔夠做實驗）
- [ ] 螺旋槳無裂、無變形
- [ ] 手機／電腦風扇正常（長時間解碼會熱）

## 環境（樓梯間）

- [ ] 現場至少兩個人：一個操作電腦，一個看住機／攔人
- [ ] 樓梯門先打開，確保氣流唔會突然改變
- [ ] 地面雜物清走（自己要行得順）
- [ ] 確認冇人正在上落樓梯；試飛期間擺「測試中」牌
- [ ] 天花高度：Tello 超聲波／TOF 有效範圍約 3m 內，太高會報錯高度

## 順序（唔可以跳）

1. **地面測試**：機放枱面、槳唔轉，`python aruco_nav.py`（乾跑）確認偵測到 6 個 marker
2. **手持測試**：手拿機對著貼紙，乾跑模式確認 1–2m 內偵測到，距離誤差 <10%
3. **低空懸停**：`--fly --takeoff --seconds 20`，唔加 `--approach`（只懸停影相）
4. **單跳測試**：只貼 2 張 marker，`--approach --stop-distance 1.0`，睇住佢只飛一兩步
5. **全程**：才試 3 層

## 緊急處理

- 失控／衝向牆：**立即 `tello.land()`**（程式 `Ctrl+C` 後會自動降落，但唔好依賴）
- 程式 crash：Tello 會在 15 秒無指令後自動降落
- 槳打到東西：即刻斷電（取出電池），唔好用手擋

## 已知限制（老實寫入報告）

| 限制 | 影響 |
|---|---|
| Tello 冇 GPS / SLAM | 冇 QR 就唔知自己喺邊；樓梯轉彎會漂移 |
| 室內光流依賴紋理 | 樓梯白牆、暗處容易失效 → 所以要每段都貼 QR 重置 |
| TOF 量的是正下方距離 | 斜飛時讀數會偏；唔可以當避障 |
| 續航約 13 分鐘 | 3 層樓要中途換電或分兩次 |
| WiFi 2.4GHz 干擾 | 樓梯間多鋼筋，影片會 Lag；所以每 3 幀才解一次 QR |
